Что делает coding agent по шагам
Шаг 1 — identity + crypto (полдня)

Identity::generate() — Ed25519 keypair.

to_x25519() — конверсия pubkey/privkey в X25519 через ed25519-dalek::SigningKey::to_scalar_bytes() или libsodium-эквивалент. Проверить тестом: X25519(priv_A, pub_B) == X25519(priv_B, pub_A).

sign(msg) -> Signature, verify(pubkey, msg, sig) -> bool.

Шаг 2 — SNS handshake (полдня)

Реализовать точно по MUSH-A'-SPEC.md §3.1:

ephemeral X25519, nonce 16 байт, Ed25519 sig над ephemeral || nonce || "SNS1".

HKDF-SHA256(shared, salt=nonce_A||nonce_B, info="Mush-SNS-v1").

Тест: два процесса обмениваются, оба получают одинаковый session_key.

Шаг 3 — framing + TCP (полдня)

[4 bytes BE length][1 byte type][CBOR payload].

Типы: 0x01 text, 0x02 sync, 0x03 handshake, 0x04 decoy.

TCP listener на 127.0.0.1:<port>.

Тест: две ноды шлют Ping/Pong CBOR-объекты.

Шаг 4 — CRDT Chat Store (день)

ChatMessage { id: ULID, sender: PubKey, content: Vec<u8>, timestamp: LamportClock, nonce: [u8;12] }.

ChatStore с merge(): дедуп по id, порядок по LamportClock.

Шифрование content на group_key (AES-GCM).

Тест: три ChatStore, разные порядки вставки, после merge — идентичные истории.

Шаг 5 — sensors (полдня)

S1: ContactRateSensor — threshold msg_count > median * 5, окно 10.

S7: DecoyEidSensor — decoy EIDs генерируются blake3(random || pubkey || epoch).

Тест: подать 50 сообщений подряд → S1 alert; отправить на decoy → S7 alert.

Шаг 6 — CLI + TUI (день)

clap для аргументов: --name, --port, --join <invite>.

Commands: /send, /join, /contacts, /sync, /flood N, /decoy, /alert, /quit.

При старте — печатать mush://<base64_pubkey>#<base64_nonce>.

Демо: два терминала, cargo run, копипаст invite, /send hello.

Что проверить после
X25519 conversion — самое частое место ошибок. Тест DH(A_priv, B_pub) == DH(B_priv, A_pub) обязателен.

Nonce freshness — старый invite должен отклоняться. Добавить тест.

Lamport clock — при merge не должно быть циклов. Проверить на 100+ сообщениях из 3 источников.

Backpressure eviction — не удаляет ли свежие сообщения вместо старых.
